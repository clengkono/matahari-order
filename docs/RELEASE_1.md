# RELEASE 1
## Customer Ordering MVP

Status:
In Development

Goal:

Deliver the first usable version of Matahari Order.

When complete, real customers should be able to place actual orders.

---

# Scope

The application shall support:

✓ Home Screen

✓ Product Cards

✓ Product Bottom Sheet

✓ Shopping Cart

✓ Cart Badge

✓ Product Search

✓ WhatsApp Order Export

---

# User Story 1

Browse products.

Acceptance Criteria

Customer opens app.

Products load.

Scrolling is smooth.

---

# User Story 2

Open Product Bottom Sheet.

Acceptance Criteria

Tap product.

Bottom Sheet opens.

Tap backdrop.

Bottom Sheet closes.

---

# User Story 3

Select Unit

Acceptance Criteria

Units displayed as chips.

Exactly one selected.

---

# User Story 4

Quantity

Acceptance Criteria

Minus

Plus

Minimum 1

---

# User Story 5

Shopping Cart

Acceptance Criteria

Add item.

Increase quantity.

Remove item.

Badge updates.

Products with different units become different cart entries.

---

# User Story 6

Search

Acceptance Criteria

Typing filters products instantly.

Case insensitive.

---

# User Story 7

WhatsApp Export

Acceptance Criteria

Press Order.

Generate WhatsApp message.

Example

2 Dus Glory

1 Bungkus Masako

3 Pcs Coca-Cola

Open WhatsApp.

Ready to send.

---

# Non-functional Requirements

Must compile using:

npm run dev

No Tailwind.

No Redux.

No Bootstrap.

No unnecessary libraries.

Plain CSS.

---

# Definition of Done

Release 1 is complete when:

A customer can:

Open app

Find product

Choose quantity

Choose unit

Add to cart

Review cart

Send order via WhatsApp

without needing assistance.
